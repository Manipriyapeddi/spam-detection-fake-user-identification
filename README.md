# Detecting Spammers and Identifying Fake Users on Social Networks

## Overview
This academic mini project explores the detection of spam content and fake users on social networking platforms using tweet data analysis.

## Key Features
- Tweet dataset analysis
- Spam content identification
- Spam URL and trending-topic analysis
- Fake user identification
- Random Forest classification

## Technology
- Java / J2EE (listed in the project report)
- Random Forest classification
- Tweet data in JSON format

## Results
The project report documents an 86% Random Forest classification accuracy in its reported experiment.

The project report and supporting documentation are included in this repository.
